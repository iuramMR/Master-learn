# Master-learn

Python 学习练习仓库，按周组织，每周一个可运行脚本与说明文档。

## 周次索引

| 周次 | 主题 | 脚本 | 说明 |
|---|---|---|---|

## 目录约定

每周一个子目录 `wN/`，内含当周脚本、示例数据与 `README.md`。

## 快速运行

```bash
cd w1
python word_freq.py input.txt
```
